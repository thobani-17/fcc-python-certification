# freeCodeCamp Python Certification

This repository tracks my progress through freeCodeCamp's Python Certification. I use it to keep my lab solutions and workshop code in one place so I can revisit them as I learn.

## Repository structure

| Directory | Contents |
| --- | --- |
| [`labs-and-workshops/`](./labs-and-workshops/) | Python lab solutions and code from guided workshops. |

## Run an exercise locally

With Python 3 installed, clone the repository and open the exercise folder.

```bash
git clone https://github.com/thobani-17/fcc-python-certification.git
cd fcc-python-certification/labs-and-workshops
```

Find a Python script you want to try and run it with `python path/to/script.py`, replacing `path/to/script.py` with the file's actual path. If your system uses `py` or `python3`, use that command in place of `python`.

## Course

The labs and workshops are part of the [freeCodeCamp Python Certification](https://www.freecodecamp.org/learn/python-v9/).
